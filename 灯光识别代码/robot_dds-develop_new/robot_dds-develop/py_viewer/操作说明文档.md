# 机器人视觉抓取控制系统操作说明文档

## 一、程序启动

### 1.1 环境准备

#### 1.1.1 设置环境变量（可选）
如果需要使用特定的CycloneDDS配置，可以设置环境变量：
```bash
export CYCLONEDDS_URI=/home/dobotpc2/Documents/robot_dds-develop/cyclonedds.xml
```

#### 1.1.2 前置条件检查
- ✅ 确保TCP服务器已启动（默认地址：127.0.0.1:65432）
- ✅ 确保无线手柄已连接并正常工作
- ✅ 确保机器人硬件已上电并初始化完成
- ✅ 确保视觉识别服务正常运行

### 1.2 启动程序

#### 1.2.1 打开Pycharm运行视觉程序
```bash
程序路径: /home/dobotpc2/Downloads/yaoshibang/detectBottleAndLight.py 
```

#### 1.2.2 进入机器人程序目录
```bash 
cd /home/dobotpc2/Documents/robot_dds-develop_20251208/robot_dds-develop/py_viewer
```

#### 1.2.3 等待视觉程序启动后运行机器人程序
```bash
python "grap_control_new_tts.py"
```

### 1.3 启动流程说明

程序启动后将自动执行以下初始化步骤：

1. **初始化机器人模型**
   - 加载机械臂模型
   - 初始化真实机器人控制（如果 `simulate = False`）

2. **建立TCP连接**
   - 连接到视觉识别服务（127.0.0.1:65432）
   - 清空接收缓冲区
   - 发送初始start信号进行通信测试

3. **初始化机器人位置**
   - AMR移动到待机点（tag_id=1008, theta=180.0）
   - 头部控制到初始角度（[0, -5]度）
   - 升降轴调整到初始位置
   - 双臂移动到初始位置
   - 双手打开到初始状态

4. **语音提示**
   - 播放TTS提示："机器人初始化完成。。"

5. **进入等待状态**
   - 程序进入主循环，等待无线手柄按键触发
   - 控制台显示："waitRT+"

### 1.4 启动成功标志

- ✅ 控制台显示绿色文字："tcp连接成功"
- ✅ 控制台显示绿色文字："TCP连接建立成功，准备就绪"
- ✅ 控制台显示："waitRT+"
- ✅ 听到语音提示："机器人初始化完成。。"

## 三、任务详细说明

### 3.1 楼宇巡检任务（R2 + X）

#### 3.1.1 任务触发
1. 按下 **R2键**（右肩键）
2. 在R2按下的同时，按下 **X键**
3. 听到语音提示："开始执行楼宇巡检任务。。"

#### 3.1.2 任务流程

**步骤1：移动到灯光检测点**
- AMR移动到灯光检测点（tag_id=1101, theta=90度）
- 如果移动状态为"A"，会先执行取放箱子操作

**步骤2：头部调整**
- 头部抬高到-15度，准备拍照

**步骤3：视觉识别**
- 通过TCP发送"light"命令触发相机拍照
- 接收视觉识别结果
- 判断灯光状态：
  - **灯光打开（ok）**：执行关闭动作
  - **灯光关闭**：直接返回

**步骤4A：如果灯光打开**
- 语音提示："灯光处于打开状态,执行关闭动作。。"
- 头部调整到15度
- 执行抓取关闭动作：
  - 双臂移动到初始位置
  - AMR移动到目标点（tag_id=1100, theta=92度）
  - 右手执行抓取动作序列
  - AMR移动到最终位置（tag_id=1008, theta=0度）
- 头部调整回-5度
- AMR返回待机点（tag_id=1008, theta=180度）
- 语音提示："楼宇巡检任务结束。。"

**步骤4B：如果灯光关闭**
- 语音提示："灯光处于关闭状态。。"
- 头部调整到0度
- AMR返回待机点（tag_id=1008, theta=180度）
- 语音提示："楼宇巡检任务结束。。"

#### 3.1.3 任务完成标志
- ✅ 听到语音提示："楼宇巡检任务结束。。"
- ✅ AMR返回到待机点（tag_id=1008）
- ✅ 机器人回到待机姿态

---

### 3.2 商业分拣任务（R2 + Y）

#### 3.2.1 任务触发
1. 按下 **R2键**（右肩键）
2. 在R2按下的同时，按下 **Y键**
3. 听到语音提示："开始执行商业分拣任务。。"

#### 3.2.2 任务流程

**步骤1：初始化准备**
- 同步所有关节角度
- 执行商业任务初始化：
  - 头部调整到-5度
  - 双手调整到初始状态
  - 双臂移动到商业任务初始位置

**步骤2：执行双站点取放料任务**
- **取料阶段**（站点1001）：
  - AMR移动到取料点（tag_id=1001, theta=0度）
  - 头部调整到30度
  - 进入视觉抓取循环：
    - 发送"resultOK"触发相机拍照
    - 接收识别结果
    - 根据识别结果执行左手或右手抓取
    - 确保左右手各抓取一个物品
  - 当两个物品都抓取完成后，退出循环

- **放料阶段**（站点10015）：
  - AMR移动到放料点（tag_id=10015, theta=270度）
  - 双臂移动到放置点上方
  - 双臂移动到放置点
  - 打开双手放置物品
  - 双臂脱离放置点
  - 双臂回到初始位置

**步骤3：返回待机点**
- AMR移动到总待机点（tag_id=1008, theta=180度）
- 双臂回到初始位置
- 头部调整到-5度

#### 3.2.3 视觉抓取说明

在取料阶段，系统会循环执行以下操作：

1. **拍照识别**
   - 发送"resultOK"命令
   - 接收识别结果（格式：RESULT:left/right, x, y, ...）

2. **抓取判断**
   - 如果识别到"RESULT:left"且左手未抓取 → 执行左手抓取
   - 如果识别到"RESULT:right"且右手未抓取 → 执行右手抓取
   - 如果识别到的物品类型已抓取过 → 跳过，继续拍照

3. **抓取完成条件**
   - 左手物品已抓取（`left_item_grabbed = True`）
   - 右手物品已抓取（`right_item_grabbed = True`）
   - 两个标志都为True时，退出循环，前往放料点

#### 3.2.4 任务完成标志
- ✅ 听到语音提示："商业分拣任务完成。。"
- ✅ AMR返回到待机点（tag_id=1008）
- ✅ 机器人回到待机姿态

## 五、注意事项

### 5.1 操作注意事项

1. **按键操作**
   - 必须先按下R2键，再按X或Y键
   - 按键操作需要在程序进入等待状态后进行
   - 如果按键无响应，检查无线手柄连接状态

2. **任务执行**
   - 任务执行过程中，请勿再次触发按键
   - 等待当前任务完全结束后再触发下一个任务
   - 注意观察控制台输出信息，了解任务执行状态

3. **视觉识别**
   - 确保视觉识别服务正常运行
   - 确保TCP连接正常（程序启动时会自动检查）
   - 如果视觉识别失败，任务可能会中断

4. **安全注意事项**
   - 任务执行过程中，确保工作区域内无人员
   - 注意观察机器人运动轨迹，避免碰撞
   - 如遇异常情况，立即按下Ctrl+C停止程序

### 5.2 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| TCP连接失败 | 视觉识别服务未启动 | 启动视觉识别服务 |
| 按键无响应 | 无线手柄未连接 | 检查手柄连接状态 |
| 任务执行中断 | TCP连接断开 | 检查网络连接，重启程序 |
| 视觉识别失败 | 相机服务异常 | 检查相机服务状态 |

### 5.3 程序配置参数

关键配置参数位于文件开头，可根据需要调整：

- `simulate`: 是否仿真模式（False=真实机器人）
- `isVisual`: 是否可视化（False=不显示）
- `tcp_vel`: 末端速度（0.7）
- `tcp_acc`: 末端加速度（20）
- `joint_vel`: 关节速度（1.4）
- `joint_acc`: 关节加速度（60）
